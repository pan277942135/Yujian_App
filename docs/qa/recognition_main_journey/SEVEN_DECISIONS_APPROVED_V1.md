# 拍照识别 · 七项用户批准行为 V1

**2026-10-17 | 范围：用例验收合同；未实施 Android 生产代码，未执行 Runtime 测试。**

| 用例 | 已批准的行为 |
|---|---|
| PER-04 | 仅 Android 允许且用户明确重试时请求一次权限；不得反复自动弹窗 |
| PER-05 | 权限不可再次请求时显示前往当前 App 设置入口；相册和返回可用 |
| PROC-07 | 等真实识别回调；超过权威超时配置触发 TECHNICAL_FAILURE；用户手动重试；旧结果作废 |
| NAV-03 | Processing 中 Back 取消/作废当前任务，回 Capture；迟到回调不可推到 Result |
| NAV-04 | Result 顶部 Back 回来源首页；本测试用户为 Empty Home，未保存记录数仍为零 |
| NAV-05 | Result 系统 Back 与顶部 Back 完全一致 |
| NAV-07 | 同一推理任务安全存活时原地恢复；任务无法安全恢复则显式重新识别或重新拍照 |

## 需要保留的验收门禁

**PROC-07 的具体超时数值尚未批准。** 不得将 220/320/350/250ms 最低动效时长或任意固定值当成推理超时。必须从明确获批准的配置获取超时值、记录取值源和触发时钟；当前该用例是行为 FROZEN、参数 BLOCKED。

**NAV-07 的 Activity 重建恢复须用真机验收。** “短暂”指同一 attempt 的所有权仍存在且能安全重连，不以臆造的后台秒数决定。重试要用新的 ID，不允许旧回调造成重复识别。

**PER-05 的权限设置文案/页面仍需与既有 Frozen 视觉合同核对。**

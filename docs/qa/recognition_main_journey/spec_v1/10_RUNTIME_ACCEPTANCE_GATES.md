# 10 · Runtime、视觉与证据 Gate 标准

**Gate 状态域：** PASS / FAIL / BLOCKED / NOT_RUN。NOT_RUN 表示没有执行证据；BLOCKED 表示前提/参数/资产/环境缺失；FAIL 只用于实际证据显示产品不满足合同。不得把 BLOCKED/NOT_RUN 自动折算成 PASS。

所有运行证据必须绑定同一 source_sha、APK SHA-256、AndroidTest APK SHA-256、model artifact SHA/版本、QA manifest SHA/版本、fixture SHA/版本、run ID 与实际 device profile。缺少必需绑定时 G12/G15 不通过；依赖上游未通过时下游 Gate BLOCKED。

Processing 视觉最短展示合同固定为 CAPTURED ≥220ms, DETECTING ≥320ms, OUTLINE ≥350ms, CLASSIFYING ≥250ms，各自只计算冻结合同定义的可见阶段间隔；需要真实 pipeline 事件与视觉最短节拍二者都满足。它们是最短视觉展示时间，不是模型超时。模型 timeout 必须由另行批准的 TOTAL_INFERENCE_TIMEOUT_MS 配置和性能数据验收；当前 PARAMETER_REVIEW_REQUIRED。

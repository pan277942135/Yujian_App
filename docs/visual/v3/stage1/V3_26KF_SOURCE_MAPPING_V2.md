## Mapping rules

1. Frame numbering inside boards is left-to-right, then top-to-bottom. If the board has no explicit frame number, the frame number is a layout-derived locator, not an authored label.
2. The 26KF Overview is a contact sheet. Its crops are not independent high-resolution masters.
3. KF14 is the KF05 path in reverse. Preserve the original Path ID and geometry; reverse direction only.
4. KF25 is a product behavior: save current catch, then return to KF00 Home. Do not invent a separate save-success animation.
5. 12.2 GLYPH_EMERGENCE is six-frame board Frame 5 between KF18 and KF19; it does not create a 27th KF.
6. Visual fish contours are references only. Runtime contour and P* must come from the trusted Mask for the current Attempt.
7. Resident G01/G02/A01/A02/C01 are Orb filaments. Task energy count is dynamic and is not inferred from Resident count.

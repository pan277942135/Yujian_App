# TopNavigation

- Back: rounded-outline icon
- Page title: DISPLAY role, dominant over utility actions
- Utility actions: lower contrast/weight than title and Hero
- Fish Guide uses book/knowledge semantics when used as a knowledge destination
- Share/Edit/Search/Filter remain utility actions, not brand accents

## Icon Action V1 binding

- Back uses `Icon Action V1 / NAVIGATION`.
- Share / Fish Guide / Search / Filter / More / page-level Edit use `Icon Action V1 / UTILITY` when they are independently tappable.
- Search-field decorative magnifier and Text Action chevron are explicitly excluded.
- All actions use a 44×44dp minimum touch target; ordinary actions do not use gold.

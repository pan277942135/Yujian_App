# Fish Card Family

## FishRecordRowCard
Use in My Catches.
- thumbnail
- species
- length / weight
- disclosure affordance
- optional low-weight meaningful-record annotation

## FishGuideCard
Use in Fish Guide.
- species identity
- natural/field-guide description
- realistic fish body
- record count as archive metadata
- carousel is allowed

Forbidden: rarity, star level, legendary glow, game-card border hierarchy.

# YuJianPrimaryCaptureButton

Shared brand component used by Empty Home, Normal Home and primary capture entry points.

## Frozen visual language
- white solid core
- thin MorningGold rim
- dark blue-gray camera glyph
- restrained highlight
- no glass-ball appearance

## Reference sizing
- visual diameter ≈168 px on 1080-wide reference canvas
- Android target ≈56 dp visual size
- touch target >=64 dp

Motion comes from the shared motion token file.

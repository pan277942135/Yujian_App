# YuJianCatchHeroCard

## Home variant
- real catch image
- species
- length / weight
- relative time + location when required by Home
- very light bottom readability gradient

## Detail variant
- real catch image
- species
- length · weight · location on the card
- no time in the current V2 detail visual
- low-weight `编辑 >` at bottom-right

## Rules
- fish is the first visual subject
- large shared radius
- no solid black information strip
- no confidence/achievement overlays
- no badge pile-up

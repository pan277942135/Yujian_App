# Cross-page Rules — Core UI V1

1. **Same World** — all six screens must feel like the same morning-lake visual world.
2. **Nature Before UI** — first impression must not be dashboard/cards/controls.
3. **Real Fish Before Data** — when a real catch image exists, it outranks statistics.
4. **One Primary Focus** — each viewport has one first visual center.
5. **Glass Is Atmosphere** — use only for readability/layer separation.
6. **Gold Is Rare** — excessive gold emphasis fails review.
7. **Achievement Below Memory** — records/progress never outrank fish/story/memory.
8. **Allow Scroll** — never crush spacing to show an entire detail/list in one viewport.
9. **No Gamification Drift** — no XP, levels, rarity, legendary cards, HUD rewards.
10. **Shared Means Shared** — camera button, hero card, icons, type roles and glass levels must not fork per page.
11. **No Background Reinvention During Micro-editing** — local UI refinement must preserve scene geometry and content unless background redesign is explicitly requested.
12. **Source Integrity** — generated substitutes cannot replace a missing frozen visual source.

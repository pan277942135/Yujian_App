# YuJian Icon Action V1

Status: **ACTIVE_CLOSURE**  
Current version: **V1 Candidate**  
Scope: **Shared Design System**

## Families

1. `NAVIGATION` — Back / Close
2. `UTILITY` — Card Flip / Share / Fish Guide / Search / Filter / More / optional page-level Edit
3. `CONTEXT` — Clear / Visibility / Voice / Add Media and other local-control actions

## Boundary

Not Icon Action:

- Primary Capture Button;
- Text Action trailing chevron;
- non-interactive Search Field leading icon;
- Filter chips / selection pills;
- decorative metadata icons.

## Current design direction

- 44×44dp minimum touch target.
- Rounded-outline vector family.
- No gold for ordinary icon actions.
- Transparent container by default.
- On complex media only: optional 36dp Mist support disc inside the 44dp hit target.
- No press scale or bounce.
- Card Flip triggers content flip; the icon itself stays visually stable.

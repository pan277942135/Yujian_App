# 我的鱼获 · Timeline Scroll V1

Status: **FROZEN**
Page: `my_catches_v2`

## 1. Timeline hierarchy

```
月份章节
  └── 日期节点 / 当日摘要
       └── FishRecordRowCard × N
```

排序：
- newest first
- 默认进入页面定位到最新鱼获
- 不反向显示“最老记录优先”

## 2. 月份

月份是章节级导航。

Rule:
- Month Header **Sticky**
- 进入下一月份后由新月份 Header 接替
- 不为每条记录重复月份

## 3. 日期节点

日期属于当天鱼获集合。

Rule:
- 日期节点随当天记录正常滚动
- 不长期吸顶
- 日期视觉比月份 Header 低一级
- 日期信息相对早期稿缩小约 10–15%
- 当日摘要进一步降权

Day summary:
- 单一有效地点：`地点 · N条鱼获`
- 多地点或无地点：`N条鱼获`
- 筛选后按可见记录重新计算

## 4. 单日记录数量

### 1–5 条
全部展开。

### 6–10 条
默认展示前 5 条，并显示：

`查看另外 N 条`

### >10 条
默认展示前 5 条，并显示：

`查看全部`

展开行为只影响当前日期组，不打散月份 / 日期结构。

## 5. 搜索 / 筛选

搜索或筛选后：
- 仍保留月份结构
- 仍保留日期结构
- 隐藏无匹配记录的空日期组
- 隐藏无可见日期的空月份组
- 日摘要按可见结果重算

不切换成独立“搜索结果页”。

## 6. 数据加载

初始优先加载最近 **3 个月**。

向下滚动到历史边界时加载更早月份。

加载更多时：
- 不跳回顶部
- 不破坏当前可见月份位置
- 不重复插入同一记录

## 7. Scroll restoration

同一次页面会话：
- 从 FishRecordDetail 返回时，恢复离开前的列表位置
- 修改搜索 / 筛选条件时，定位到新的结果顶部 / 最新可见记录
- 清除搜索 / 筛选后回到最新可见时间段

## 8. Page identity

Timeline 是“记忆档案”，不是 analytics dashboard。

禁止：
- 排名榜
- 大面积统计仪表盘
- 连续成就徽章墙
- 用图表替代真实鱼获记录

## 9. Empty states

三类必须分开：
- Archive Empty
- Search Empty
- Filter Empty

Search / Filter Empty 不丢失时间档案页面框架。

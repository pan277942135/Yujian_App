# 我的鱼获 · Timeline Scroll V1

Status: **FROZEN**
Page: `my_catches_v2`

## 1. Timeline hierarchy

```
月份章节
  └── 日期节点 / 当日摘要
       └── FishRecordRowCard × N
```

排序：
- newest first
- 默认进入页面定位到最新鱼获
- 不反向显示“最老记录优先”

## 2. 月份

月份是章节级导航。

Rule:
- Month Header **Sticky**
- 进入下一月份后由新月份 Header 接替
- 不为每条记录重复月份

## 3. 日期节点

日期属于当天鱼获集合。

Rule:
- 日期节点随当天记录正常滚动
- 不长期吸顶
- 日期视觉比月份 Header 低一级
- 日期信息相对早期稿缩小约 10–15%
- 当日摘要进一步降权

Day summary:
- 单一有效地点：`地点 · N条鱼获`
- 多地点或无地点：`N条鱼获`
- 筛选后按可见记录重新计算

## 4. 单日记录数量

### 1–5 条
全部展开。

### 6–10 条
默认展示前 5 条，并显示：

`查看另外 N 条`

### >10 条
默认展示前 5 条，并显示：

`查看全部`

展开行为只影响当前日期组，不打散月份 / 日期结构。

## 5. 搜索 / 筛选

搜索或筛选后：
- 仍保留月份结构
- 仍保留日期结构
- 隐藏无匹配记录的空日期组
- 隐藏无可见日期的空月份组
- 日摘要按可见结果重算

不切换成独立“搜索结果页”。

## 6. 数据加载

初始优先加载最近 **3 个月**。

向下滚动到历史边界时加载更早月份。

加载更多时：
- 不跳回顶部
- 不破坏当前可见月份位置
- 不重复插入同一记录

## 7. Scroll restoration

同一次页面会话：
- 从 FishRecordDetail 返回时，恢复离开前的列表位置
- 修改搜索 / 筛选条件时，定位到新的结果顶部 / 最新可见记录
- 清除搜索 / 筛选后回到最新可见时间段

## 8. Page identity

Timeline 是“记忆档案”，不是 analytics dashboard。

禁止：
- 排名榜
- 大面积统计仪表盘
- 连续成就徽章墙
- 用图表替代真实鱼获记录

## 9. Empty states

三类必须分开：
- Archive Empty
- Search Empty
- Filter Empty

Search / Filter Empty 不丢失时间档案页面框架。


## 10. 单日折叠 / 展开交互冻结

### 1–5 条
- 不显示折叠控制；
- 所有 FishRecordRowCard 顺序展示。

### 6–10 条
- 默认展示最新 5 条；
- 第 5 条后显示轻量展开行：
  `查看另外 N 条`
- 点击后在**原日期组内部**展开剩余记录；
- 不跳新页面；
- 不打开弹窗；
- 展开后底部显示弱操作：
  `收起`

### >10 条
- 默认展示最新 5 条；
- 第 5 条后显示：
  `查看全部 N 条鱼获`
- 点击进入**当天鱼获详情**；
- 当天详情只展示该日期的全部 FishRecord；
- 保留日期、地点摘要与 Growth Mark；
- 返回后恢复原 Timeline 的滚动位置与折叠状态；
- 不在主 Timeline 无限展开，避免单日记录过多导致时间轴失控。

### 展开 / 返回状态
- 6–10 条的原位展开状态在同一次 My Catches 会话内保持；
- >10 条从当天详情返回时恢复原 Timeline 位置；
- 从 FishRecordDetail 返回后恢复；
- 搜索 / 筛选条件变化时重新计算，并回到对应日期组默认折叠态。

### 视觉
展开行属于 Timeline furniture：
- 比 FishRecordRowCard 弱；
- 使用文字 + 极轻 chevron；
- 不使用实心主按钮；
- 不使用金色强调；
- 不改变日期组背景。

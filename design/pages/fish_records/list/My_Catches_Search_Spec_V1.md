# 我的鱼获 · 搜索交互 V1

Status: **FROZEN**
Page: `my_catches_v2`

## 1. 入口

搜索是页面内操作，不进入新路由。

点击搜索框后：
- 搜索框原位进入 Focused 状态；
- 键盘打开；
- 页面标题、筛选入口与 Timeline 框架不消失；
- 不跳转到“搜索页”；
- 不出现独立全屏搜索界面。

## 2. 搜索范围

V1 自由文本搜索冻结为：
- 鱼种
- 地点
- 日期

特殊记录统一通过“特殊记录”筛选维度完成，不与自由文本搜索重复。

Placeholder:

`搜索鱼种、地点或日期`

## 3. 输入与结果

- 输入即时过滤，不需要额外“搜索”按钮；
- 去除首尾空格；
- 查询为空时恢复完整 Timeline；
- 搜索结果仍保持：
  `月份 → 日期 → FishRecordRowCard`
- 隐藏无结果的日期组；
- 隐藏无结果的月份组；
- 日期摘要按搜索后的可见记录重新计算；
- 搜索时不改变用户的筛选条件。

## 4. Focused state

Focused:
- 搜索框保持当前页面宽度；
- 左侧搜索 icon 保留；
- 有输入时右侧显示清除 `×`；
- 不额外出现“取消”文字按钮，避免横向跳动；
- Filter 入口仍可使用。

## 5. 搜索结果状态

示例查询：
`草鱼`

如果有结果：
- Archive summary 改为结果数量；
- Timeline 直接收敛到匹配月份 / 日期；
- 卡片结构完全不变；
- 不高亮到破坏卡片阅读的程度；
- V1 不做全文关键词黄色标记。

## 6. Search Empty

保留当前查询文本，例如：

`🔍 鳄鱼  ×`

文案：

**没有找到相关鱼获**

辅助文案：

**你可以搜索：鱼种、地点、日期**

唯一恢复动作：

**清除搜索**

禁止：
- “重新拍摄”
- “记录第一条鱼”
- 推荐其它鱼种
- 清空用户现有筛选条件

清除搜索后：
- query 置空；
- 保留原筛选条件；
- 回到筛选条件下的 Timeline。

## 7. 与 Filter 的组合

Search 与 Filter 可以同时生效。

Rule:
`SearchMatch AND FilterMatch`

如果同时存在搜索和筛选，结果为空时：
- 若 query 非空，优先显示 Search Empty；
- 清除搜索后，如果筛选仍无结果，再进入 Filter Empty。

## 8. Runtime gap

当前 Runtime 只搜索鱼种 / 地点，尚未覆盖日期搜索。

这属于 Development Handoff Gap，不修改本设计冻结。

# 我的渔境｜方案与交互规范 V1

**状态：产品关系与核心规则已确认；主页面高保真待选版。**  
**用途：Design Manager「我的鱼获 → 我的渔境」工作区。**  
**范围：归档既有阶段方案与已定规则；不是新增独立产品导航，也不代表 Android 已实现。**

## 入口与关系

- 「我的鱼获」与「我的渔境」是同一批鱼获数据的两种视图。
- 从「我的鱼获」右上角鱼与水波图标切换进入渔境；回切后仍回到原鱼获记录。
- 过渡表达鱼获从记录进入水域即可，不增加独立 Tab、一级菜单或另一套记录数据。

## 鱼与水域

- 每条真实鱼获对应一个独立 FishInstance，由该条鱼获的真实照片 / Fish Asset 派生；不合并鱼获，不加入虚拟鱼。
- 渲染采用 2.5D：Fish Sticker、Mesh Deformation、Motion Engine、Water Shader、Depth Layer。
- 鱼体须保留原鱼获身份；显示尺寸按记录长度表达。概要只显示鱼获数与鱼种数，重点鱼可以轻量突出，不做勋章、皇冠、星级或榜单。
- 数量较多时用景深分层、LOD 与自然进出水域控制可读性；鱼获仍全部保存。未满足鱼获数与不同鱼种数的双重进阶条件前，限制重复鱼进入当前水域展示；具体数值阈值待独立确认。

## 进阶结构

| 水域阶段 | 级数 | 已定形态要点 |
|---|---:|---|
| 鱼缸 | 3 | 首期代表性小型鱼缸阶段；不要求一次实现全部后续场景 |
| 鱼塘 | 5 | 单池 → 横向长塘 → 深浅分区 → 主塘与浅湾 → 完整曲湾 |
| 湖泊 | 7 | 单湖湾 → 内凹双浅湾 → 中央深水 → 岬角分水 → 山影纵深 → 群湾 → 秘境大湖 |

- 湖泊 2 的关键形态是向内凹入的双浅湾。
- 湖泊 4 的关键形态是伸入水中的陆岬 / 半岛，将水面分开。
- 级别顺序是已定方案；一次只实现代表阶段，其余阶段板用于回顾与后续设计，不要求首期制作全部 15 级动态场景。

## 视觉边界

- 自然水域、清晨湖水、淡灰蓝绿与少量淡金；表达安静的个人鱼获记忆。
- 不做完整 3D 游戏，不用 HUD、关卡奖励、游戏化徽章，不替换或重画真实鱼体。
- 本工作区登记的鱼塘和湖泊 PNG 是现有概念阶段板，仅供形态与阶段关系参考；不是当前主页面视觉权威，也不是可直接用于运行时的鱼体素材。
- 具体主页面高保真由用户后续选定后再更新视觉 Authority。

## 首期范围与待定项

- 首期只实现一个代表性水域阶段；鱼缸是当前 MVP 起点方向。
- 后续阶段沿既定 3 / 5 / 7 级结构扩展。
- 鱼获数与鱼种数的具体进阶阈值、Android Renderer 方案仍待实现前确认；本规范不虚构阈值或性能指标。

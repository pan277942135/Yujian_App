# R01 · 主视觉细节 · 生成规范 V1

状态：**生成规范已冻结 / 最终视觉图待补**

归属：

`识别过程 → 03 · 图层与组件归属 → AI 边缘光场 V1 → 03 · 视觉参考集 → R01 · 主视觉细节`

## 1. 目的

R01 用来确定 **AI 边缘光场的整体视觉质感、能量感与代表性主画面**。

它只回答：

> 这套 AI 光场整体应该长什么样。

它不定义 Runtime 实现，不定义代码，不定义平台绘制方式。

## 2. 画面形式

- 9:16 竖屏；
- 单张完整真实钓鱼照片；
- 无设备外框；
- 不放技术参数；
- 不做拆层示意；
- 不做多状态拼图。

R01 必须是一张能够直接判断“整体好不好看”的完整主视觉。

## 3. 整体构图

必须同时出现四个断开的能量岛：

- 左上金色；
- 右上蓝色；
- 左下金色；
- 右下蓝色。

主次关系：

```text
右上蓝色 > 左上金色 > 左下金色 > 右下蓝色
```

其中：

- 右上蓝色 = 唯一主能量区；
- 左上金色 = 第二视觉支点；
- 左下金色 = 低位暖色承托；
- 右下蓝色 = 最弱冷色收尾。

四个能量岛之间必须保留明显的安静断口。

## 4. 视觉重点

这张图优先验证四件事：

1. **局部受光**
   - 照片边缘要像真的被蓝 / 金光照到；
   - 不能只是把发光线贴在照片上。

2. **能量带层次**
   - 外层柔光；
   - 中层发光主体；
   - 内层细亮 Core；
   - 第一眼应先读到“光场”，第二眼才看到“线”。

3. **局部细节**
   - Hairline；
   - Hot Node；
   - Sparse Particle；
   - 都可以在 R01 中比最终产品更明显，用于确认视觉语言。

4. **AI 存在感**
   - 本轮不追求极度克制；
   - 允许整体偏强；
   - 优先确认“明显、好看、有 AI Moment”。

## 5. 必须保持

不得因为探索视觉强度而改变：

- 四岛数量；
- 四岛所在区域；
- Quiet Gap；
- 右上蓝色主岛身份；
- 蓝右 / 金左的大关系；
- 中央真实照片主阅读区。

## 6. 明确禁止

禁止出现：

- 完整四边发光框；
- 椭圆轨道；
- HUD / Scanner；
- 雷电；
- 激光；
- 电路板；
- 四角等亮；
- 对称边框；
- 满屏粒子；
- 全屏蓝金染色；
- 粗霓虹 Core；
- 让 AI 光效压过真实照片。

## 7. 本轮强度原则

R01 可以比最终 Runtime 更强。

可以增强：

- 局部受光；
- 外层 Bloom；
- 中层 Glow；
- Hairline 可见度；
- Hot Node；
- Sparse Particle。

但只能增强**现有冻结结构**，不能通过新增更多路径或更多能量岛来增强。

## 8. 判断标准

生成后只判断以下问题：

- 第一眼仍然是真实钓鱼照片吗？
- 第二眼能明显感受到 AI 光场吗？
- 四岛主次清楚吗？
- 右上蓝色是不是唯一主能量区？
- 光像存在于空气和环境中，而不是贴图吗？
- 整体有没有高级、自然、有能量的感觉？

如果这些问题还没有统一答案，R01 不进入 FROZEN。

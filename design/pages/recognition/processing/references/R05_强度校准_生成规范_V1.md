归属：

`识别过程 → 03 · 图层与组件归属 → AI 边缘光场 V1 → 03 · 视觉参考集 → R05 · 强度校准`

## 1. 目的

建立 AI 边缘光场的视觉强度参照区间，明确上限、目标值与最低可接受值。

## 2. 画面形式

同一照片、同一四岛几何、同一构图，横向或纵向并列三版：强表现 / 目标 / 最低可接受；只改强度，不改结构。

## 3. 构图要求

- 强表现：用于确认视觉上限，受光、Bloom、Hairline、Node、Particle 都更明显
- 目标：用于后续最终产品视觉的候选基准
- 最低可接受：仍能明确看出 AI 边缘光场身份，但再弱就会失去存在感
- 三版必须严格复用同一照片与同一几何

## 4. 视觉重点

- 比较局部受光强弱
- 比较 Bloom 与 Core 的相对关系
- 比较 Hairline / Node / Particle 的可见度
- 比较 AI 存在感与照片主导权之间的平衡
- 找到“看得见”与“不过度”的目标区间

## 5. 必须保持

- 三版四岛位置完全一致
- 三版 Quiet Gap 完全一致
- 三版主次关系一致
- 只改变视觉强度与细节显著度
- 最低可接受版仍必须读成同一个 AI 边缘光场系统

## 6. 明确禁止

- 三版改不同路径
- 三版改变岛数量
- 强版通过增加额外光线来变强
- 弱版通过删除主岛来变弱
- 把强度校准做成 FULL/BALANCED/LITE 的运行时实现说明
- 用曝光整体提高或降低替代光场强度变化

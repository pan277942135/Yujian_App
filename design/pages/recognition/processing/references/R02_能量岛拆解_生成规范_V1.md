# R02 · 能量岛拆解 · 生成规范 V1

状态：**生成规范 FROZEN / 现有视觉稿保留 / 文字纠偏为强制验收条件**

归属：

`识别过程 → 03 · 图层与组件归属 → AI 边缘光场 V1 → 03 · 视觉参考集 → R02 · 能量岛拆解`

## 1. 目的

把单个能量岛内部的视觉结构讲清楚，让开发和验收明确：

> 一个能量岛不是“一根发光线 + 模糊”，而是照片环境受光与多层光学结构共同形成的局部现象。

R02 只解释**单岛内部怎么长**，不负责四岛整体位置与拓扑。

## 2. 光学层级

固定阅读顺序：

1. 局部环境受光 / Receiving Light
2. 外层光晕 / Outer Bloom
3. 中层光带 / Mid Glow
4. **核心亮线 / Primary Core**
5. 伴随细丝 / Companion Hairline
6. 微细丝 / Micro Hairline（仅 B_UR）
7. 能量节点 / Hot Node
8. 稀疏粒子 / Sparse Particle

其中 Mid Glow 承担主要“能量带”体积感；Primary Core 必须是最细、最亮、最清晰的精确骨架。

## 3. 数量与颜色约束

- Primary：1 条；
- Companion：1 条；
- Micro：仅 B_UR 允许 1 条短线；
- Hot Node：局部峰值，不是独立光球；
- 同屏明显粒子建议 3–5 个以内；
- B_UR 的 Primary / Companion / Micro 全部保持蓝色系；
- 暖金色可以来自真实夕阳或环境反射，但不得被开发成 B_UR 内独立 Gold Filament。

## 4. 开发重点

- 第一眼先读到环境受光与光场，不是 Core；
- Core 不得做成“主光带”或粗霓虹管；
- Companion 必须短于、弱于 Primary，且不做恒定平行；
- Micro 更短、更细、更弱，只用于 B_UR 增加局部层次；
- Node 半径要小、无星芒，只比所在 Core 局部略亮；
- 粒子仅作为空气细节，不承担运动主体；
- 不允许雷电式分叉、树枝式能量或铁路式多线。

## 5. 验收重点

验收时必须逐项检查：

- [ ] Primary 只有 1 条；
- [ ] Companion 只有 1 条；
- [ ] Micro 仅 B_UR 且最多 1 条；
- [ ] Primary Core 明显细于 Mid Glow；
- [ ] Node 无星芒、无灯泡感；
- [ ] 粒子稀疏，不形成星空；
- [ ] B_UR 内没有独立金色能量路径；
- [ ] 无雷电分叉；
- [ ] 无平行铁路式 Hairline；
- [ ] 去掉 Core 后仍能感受到环境受光和 Bloom。

## 6. Authority 边界

醒目规则：

> **本图只解释单岛内部光学层级，不代表四岛整体拓扑。**

因此现有 R02 视觉稿无需为了上述三个局部偏差重新生成。

如果现有视觉稿与文字规范有冲突：

> **以本规范文字 + Static Shape / Rendering Contract 为准。**

四岛位置、Quiet Gap、Primary / Secondary 归属由 Static Shape 和 R03 负责。

## 7. 明确禁止

- 把 Core 做成粗主光带；
- 雷电式分叉；
- 多条 Companion；
- 非 B_UR 的 Micro Hairline；
- 星芒 Node；
- 大量粒子；
- B_UR 内独立金色能量路径；
- 从 R02 推导闭环、边框或四岛整体位置。

## 8. 当前状态

> **不再要求重新生成 R02。现有视觉稿用于解释层级；开发与验收必须以本规范的纠偏条款为准。**

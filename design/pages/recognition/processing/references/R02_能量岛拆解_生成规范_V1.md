## 1. 目的

把单个能量岛内部的视觉结构讲清楚，让人一眼看懂它不是“发光线 + 模糊”，而是局部受光与多层光学结构。

## 2. 画面形式

建议横向或方形单张规范图；左侧完整岛效果，中间局部放大，右侧视觉层次拆解；不出现代码、平台 API 或实现参数。

## 3. 构图要求

- 默认以右上蓝色主岛作为拆解对象
- 必须同时保留真实照片环境作为受光背景
- 拆解顺序从照片环境到能量细节，而不是从线条开始
- 完整效果与拆解后的各层必须能对应回同一个局部

## 4. 视觉重点

- 第一层：局部受光，说明照片边缘真的被照亮
- 第二层：外层光晕，形成空气中的能量扩散
- 第三层：中层发光，形成能量带主体
- 第四层：核心亮线，保持细、亮、干净
- 第五层：伴随细线与微细线，提供高频纹理但不成为第二主线
- 第六层：热点与稀疏粒子，只作为局部峰值与环境细节

## 5. 必须保持

- 右上蓝色主岛仍是一个完整局部现象，而不是拆成多个独立装饰物
- 核心亮线不能脱离光晕单独成立
- 伴随细线必须短于、弱于主能量带
- 热点必须依附于主能量带局部峰值
- 照片环境始终参与光学效果

## 6. 明确禁止

- 做成技术爆炸图或工程剖面图
- 把各层画成平行彩色条
- 把热点画成独立圆球
- 把粒子画成星空
- 让拆解图比完整效果更像 HUD
- 把光场解释成单根霓虹线

## 1. 统一坐标、采样与可复现

- W/H = EXIF 正向处理后，实际显示的照片前景尺寸（CSS px）；L = 可信鱼体 Mask 的显示主轴长度（CSS px）；u=x/W、v=y/H 为归一化照片坐标。照片留白和导航栏绝不参与光场。
- 照片、BBox、Mask/contour、环境水光、鱼体金光和 RR09 Residual Trace 必须复用唯一原图 SHA + PhotoSession ID + 统一 M(t)；不许针对每层重新裁剪或拟合。
- 噪声种子固定为照片 SHA、Session ID 与配置版本散列；每次暂停、跳帧、重播给定相同输入都输出相同画面。不可每帧随机产生新焦散位置。
- 时间函数由单调 elapsedMs 决定。相对视觉强度 0–100 **不是**透明度百分比，不许直接赋值给 Shader Alpha。冻结数值必须被每一段插值精确命中；推荐带端点约束的 smoothstep / shape-preserving monotone cubic，禁止过冲。

## 3. 水光颜色与空间分布（全部为首轮候选）

- 深水蓝绿 #2D7C89、清晨水青 #67BDCA、银蓝反射 #C1E9EE、淡日光金 #F2D29B。光场颜色贡献占比建议：冷色 70–80%、银蓝 15–20%、暖金 5–10%。**这些不是照片整体滤镜。**
- 照片最下方 20% 先苏醒；传播前沿参考：P1 v≈0.85、P2 v≈0.62、P3 v≈0.53；平均上行约 0.30–0.40H/s。前沿是渐隐概率包络，不是可见的水平扫描边线。
- 在 360×640 附近的手机参考显示照片，建议约 10–18 个多尺度不规则柔斑；宽 0.06–0.18W，高 0.035–0.12H；低速漂移 0.01–0.03W/s；边缘羽化 0.018–0.045W；局部峰值 Alpha 0.12–0.20，必须按原图亮度门控。
- 关键帧**可见覆盖率候选**：P0 0%、P1 4–8%、P2 15–25%、P3 25–38%、P4 20–30%、P5 12–20%、P6 3–8%、P7 0%。覆盖率需使用有效亮度差的阈值与图层隔离测量，不把半透明整屏背景计入。
- 水纹 1–3 组、空间波长 0.16–0.36W、相位 0.5–1.2 cycle/s；局部折射位移 0.3–0.9 CSS px，上限 1.2px。禁止机械条纹、环形扫描、蜘蛛网高亮、遮挡鱼眼和鱼鳞。

## 4. 金光聚焦（首轮候选）与已冻结几何

- P2 初期暖金影响范围距真实鱼体外缘约 0.22–0.28L；P3→P4 平滑收敛，到 P4 主 Halo 范围约 0.06–0.10L；候选聚焦收缩速率 0.25–0.40L/s；真实源几何必须来自一份可信 Mask 的 signed distance field，而非鱼体外接框。
- 颜色：弱金 #E7CE96 → 过渡 #F2C978 → 核心 #FFE3A6。三层参数：
| 层 | 候选色 | 模糊/宽度（CSS px） | 候选峰值 Alpha | 视觉职责 |
|---|---|---|---|---|
| Core | #FFE3A6 | 1–2.5 | 0.45–0.70 | 细、较清晰，顺真实鱼体轮廓 |
| Soft Glow | #F6C771 | 4–10 | 0.18–0.32 | 同几何内外柔和扩散 |
| Halo | #DBA34D | 12–28 | 0.06–0.15 | 较宽、低亮度且不可形成独立光圈 |

以上 CSS px 仅适合参考手机尺度；其他尺寸根据 L 统一缩放并约束，禁止每层重新拟合几何。鱼眼、鳞片、鳍条、尾鳍必须保留，鱼体 ROI 高光裁切比例候选 ≤1%。P4–P7 三层不呼吸、不闪烁。

**Mask 安全边界：** 仅 TRUSTED_MASK 才能描画精准轮廓和可信金光转移；TRUSTED_BBOX_ONLY 最多低强度柔和区域提示，不能沿矩形画鱼轮廓；NONE/STALE 关闭精准描光和旅行光路，保留照片接续与克制中文标题回退。SAM 的启发式 GOOD 不构成生产 Mask 资格。

## 5. P4→P7 外围退场：独立控制

从 1550ms 到 2800ms，按冻结相对强度 60→35→10→0 同时减弱焦散面积、局部 Alpha、水纹位移及外围折射；不得只改变整屏 opacity。聚焦三层仍按 100→100→100→100 稳定保持。

P7 的环境焦散像素贡献、外围折射和水纹位移应严格为零；允许源照片原有反光仍然存在。P7→R0 的原图 SHA、轮廓位置和核心金光不得闪变。

## 7. 光学实现算法与画面保护

- 七层仍按原 SWOS V1 的职责实现：Photo Base、Ambient Water、Caustic Field、Ripple Field、Peripheral Refraction、Fish Focus、Residual Trace；Fish Focus 的 Core/Soft/Halo 是同层内的三个子通道。
- 稳定种子生成多尺度低频不规则位移和斑块权重：A(x,y,t)=ambientAnchor(t) × softFront(v,t) × causticNoise(u,v,t) × sceneLuminanceGate(u,v) × photoClip(u,v)，再归一化映射为受限 Alpha。**不得 A=整屏统一滤镜**。
- FishGlow(x,y,t) 由唯一 Mask signed distance field、局部源图亮度及 fishGoldAnchor(t) 控制三个半径通道；Mask/光效与照片统一 M(t) 变换。
- 默认 WebGL2；能力不足时复用缓存低分辨率 Canvas2D，最后退为保留照片/路由/CTA 的静态采样。降级不改变 15 帧时序、照片身份和业务结果。
- 建议环境冷光 soft-light / 受限 screen，焦散及金光局部 screen，线性光空间计算或经过验证的等效混合；禁止过曝、生成水下场景、遮挡人脸和鱼体细节。

- 参考照片坐标：同一照片/Mask 的重投影最大误差候选 ≤2 CSS px；参考 360×640 的 R0.5 几何与冻结数值偏差候选 ≤2 CSS px；R5 粒子数量 =0。
- 验收矩阵：九视口，横竖图、EXIF 旋转、夜拍、浅/深色鱼、人物背景、Mask 不可信；必须检查照片不拉伸、中文字形、CTA 与安全区。

- 证据必须包括准确的 Sites 源码 SHA、设计 main SHA、当前参数 JSON 摘要、照片 SHA/许可、Mask 来源、浏览器/DPR/视口、15 帧截图、实际连续录屏、几何测量与原图对照及用户验收结论。

**Gate 分类：** G1 合同权威与引用同步；G2 照片/Mask/几何来源；G3 光学与冻结强度；G4 RR09 连续性/中文字形；G5 多视口/真实性能；G6 产品负责人高保真视觉签核。

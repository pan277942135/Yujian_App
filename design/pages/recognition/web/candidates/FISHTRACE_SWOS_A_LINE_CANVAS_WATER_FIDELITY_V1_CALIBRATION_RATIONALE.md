## Prior exact-head evidence

The baseline browser run was GitHub Actions run 40354907421 on candidate SHA 3948db673be4aead852a82cd3c4ddba6b4305c2f. It measured Region A composited RGB absolute difference at 3.873/255 for P2 and 3.940/255 for P3, both below their respective contract bands. P1 was 2.725/255. ## Confirmed cause

The caustic draw path calculated min(single_patch_cap, channel_strength × response × patch_weight). With the prior response of 0.55, P2's 0.42 channel value produced 0.231 before patch weight, so P2 and P3 both commonly reached the 0.22 cap. This flattened the expected P2-to-P3 rise. The original uniform sampler also selected average patch dimensions well below the permitted maximum, limiting spatial coverage.

## Prior exact-head evidence

The baseline browser run was GitHub Actions run 40354907421 on candidate SHA 3948db673be4aead852a82cd3c4ddba6b4305c2f. It measured Region A composited RGB absolute difference at 3.873/255 for P2 and 3.940/255 for P3, both below their respective contract bands. P1 was 2.725/255. P0 and P7 had zero canvas alpha and zero image difference. Forbidden Zone leakage was zero for all measured keyframes.

## Confirmed cause

The caustic draw path calculated min(single_patch_cap, channel_strength × response × patch_weight). With the prior response of 0.55, P2's 0.42 channel value produced 0.231 before patch weight, so P2 and P3 both commonly reached the 0.22 cap. This flattened the expected P2-to-P3 rise. The original uniform sampler also selected average patch dimensions well below the permitted maximum, limiting spatial coverage.

## Candidate correction in commit d410680a000aab98ff30a3967fa9fe2d9b561348

- Keep the exact P0–P7 times and channel multipliers, A/B/C/D region geometry, 18-patch count, aspect and angle bounds, and 0.22 / 0.14 per-patch caps.
- Use a 0.42 response so P2 retains headroom and P3 can reach the cap.
- Sample patch dimensions from 0.16–0.18 W by 0.052–0.065 W, within the existing size contract; spread fixed-seed centers deterministically.
- Broaden the tapered patch face profile without adding particles, changing blend modes, or generating per-frame randomness.

This note records the evidence motivating the candidate change. The new candidate's pass/fail status must be read from browser evidence generated by the matching final source SHA; this baseline run is not evidence of V1 acceptance.

## A-line visual structure update 05

Exact-head Chromium run 40364766919 on `5c888a8f256a4227b97af094b80ef981a5e5607a` measured P3 at 8.258/255 and P4 at 7.819/255, below their candidate bands; P0/P7 and Forbidden Zone leakage were zero. The P3 composite showed disconnected, sticker-like patch islands. Source inspection confirmed the geometric cause: all 18 patch centers were independently selected by maximin spread. The five group labels were used for later motion only, so they did not create spatially coherent groups.

Candidate revision `A_LINE_P3_CLUSTERED_FIELD_CALIBRATION_05` spreads one deterministic anchor per group-zone, then places remaining patches with seeded local offsets of 0.025–0.07 W constrained to the same A/B/C polygon. It retains the exact user-specified polygons, five group counts, 13/4/1 zone counts, 18 patches, shape/angle/opacity limits, three layers, channel strengths, P0–P7 times and 2800ms duration. The anchor-and-offset placement replaces independent per-patch maximin placement; it does not change the patch geometry contract or add a new rendering layer.

This revision is still a candidate. No same-head browser run has yet established the P3/P4 targets or a visual improvement, and the private SWOS V0.3 image bytes are not available in the checkout for direct image-to-image comparison. Do not mark it visually approved on the strength of code or pixel metrics alone.

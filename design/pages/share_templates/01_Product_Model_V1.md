# 分享模板 · 01 · 产品模型 V1

Status: **FROZEN**

## 1. Purpose

Turn real FishRecord / fishing-history data into a shareable memory artifact.

The share system is not:
- a free-form poster editor;
- a game achievement system;
- a generic social-media editor;
- a place for invented AI stories.

## 2. V1 template families

Exactly two:

### T01 · 战绩卡

Data-forward.

Focus:
- a selected time range;
- strong summary;
- Fish Sticker visual;
- Top 1–3 highlights;
- all remaining species/count information.

### T02 · 水边故事

Photo/story-forward.

Focus:
- 1–3 real user photos;
- light statistics;
- all species/count information;
- optional user-authored story text.

No Top-fish ranking presentation.

## 3. Template and time range are independent

The user chooses:

`Template Type × Time Range`

rather than selecting a different template for every period.

Current time range:
- 今天
- 本周
- 本月
- 自定义

## 4. Historical P08 model

Historical implementation/reference:
- 单条
- 今日
- 本周
- 本月
- 本年
- 累计

This is **SUPERSEDED PRODUCT IA**.

Do not restore six template categories to current Design Manager/runtime.

## 5. Editing boundary

V1 uses fixed templates.

Allowed product direction from prior design:
- choose template;
- choose time range;
- choose representative content where supported;
- limited content visibility/selection.

Forbidden:
- arbitrary drag/drop;
- free typography;
- free stickers/decorations;
- unrestricted layout editing;
- layer editor;
- Photoshop-like controls.

## 6. Design tone

Frozen prior direction:
- natural;
- clean;
- premium;
- light AI;
- fishing-memory oriented.

Avoid:
- HUD;
- neon;
- game-card rarity;
- heavy achievement decoration;
- technology-dashboard presentation.

Existing recovered images may contain stronger gold/glass experimentation; those visuals remain historical iterations until a visual freeze decision is made.

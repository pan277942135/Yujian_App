# YuJian Experience Governance

This directory defines the governance rules for the YuJian / 渔见 experience source of truth.

The source of truth is not limited to static visual design. A production experience may include:

- Visual
- Motion
- Haptic
- Sound
- Behavior / state semantics
- Assets
- Runtime mapping
- Evidence / acceptance

The normative specification is:

`YuJian_Experience_Source_of_Truth_V1.md`

The global implementation inventory is:

`../registry/experience_registry_v1.json`

New feature packages should start from:

`../templates/FEATURE_EXPERIENCE_PACKAGE_TEMPLATE.md`

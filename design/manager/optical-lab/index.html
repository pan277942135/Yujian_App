Stage A
当前 Android · Paint MaskFilter

原生实现以 Paint.setMaskFilter 做局部 Blur。浏览器 Canvas 的 shadowBlur 仅作近似，不能代表 Android 输出。

硬件 Canvas 友好 · Path / Gradient 叠层

Receiving 用 RadialGradient；尾段用 LinearGradient；Bloom 以多次宽 Path 低 Alpha 叠层近似，避免 setMaskFilter。

软件离屏缓存 · Blur 近似

将静态光学层缓存到 RGBA 离屏画布，再合成到照片；浏览器模糊核与 Android 软件 Canvas 仍需实机校准。

  • API 28 优先方向：先验证硬件渐变分层，后续 Android 端保留真实 Canvas/Path/Shader 实现；只有明确光学收益且帧预算足够时才测局部软件层。
  • 静态选择：PENDING · 本页不自动伪造视觉 PASS
  • 性能成本：浏览器开销只记录 draw 路径；Android fps、分配量与 GPU 代价待设备测量。
